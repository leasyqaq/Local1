# SciBench Self-Consistency 实验协议与验收

在同一批 100 道 SciBench 数值原题上，比较三次采样后投票能否提高单次采样 CoT 的正确率。现有贪心 CoT 结果作为另一条基线。沿用 Qwen3-1.7B Q4_K_M、llama.cpp b12404、固定题库、CoT 提示词、输出上限和评分代码。见 [原 CoT 实验](../Direct_CoT/实验结果.md)。

| 组别 | 答案来源 |
|---|---|
| 贪心 CoT | 原正式实验的 CoT 原始输出，同题独立评分核对。 |
| 单次采样 CoT | 每道题第 1 次采样的答案。 |
| 三次采样后投票 | 同一道题的 3 份采样输出，按固定规则选一份。 |

采样参数固定为 `temperature=0.7`、`top_k=20`、`top_p=0.8`、`min_p=0`、输出上限 768 token，关闭内建 thinking。用固定字符串、题目 ID 和样本序号生成独立的可复现种子。每次采样均使用同一个原始提示词，模型看不到前一次的输出。

## 投票规则

1. 使用原解析器提取最终答案。格式可解析且指定单位匹配的样本可以投票。达到长度上限的输出保留，能解析出符合格式的答案时照常处理。
2. 按样本 1、2、3 依次尝试归组。两个近似数需满足 `|a-b| ≤ 0.01 × max(|a|, |b|)`，且新成员要与组内所有成员都满足此条件。若符合多个组，加入先建立的组。零只与零相合。
3. 选票数最多的组，平票时选最早建立的组。提交该组最早出现的原始答案。若三个样本都不能投票，提交第 1 份原始输出，按原规则评分。

票选只使用生成的数值及题目指定单位。正式正确率在选定答案之后比较参考值，沿用原任务的 1% 容差和 5% 敏感性检查。统计三组正确率、相对第 1 次采样的改对和改错、按题目家族重采样的 95% 区间、输出 token 和总作答耗时。另报告三次各自的成绩，观察单次基线对种子的敏感性。

## 验收标准

1. 离线验证近似数聚类、非传递链、平票、无有效答案以及无效第 1 份时的回退。
2. 用与正式集无已标记家族重叠的 4 道题预跑 12 次，核查题目、提示词、种子、原始输出、判分、聚类和投票。每题至少两份能解析且单位匹配，至少一道题的三份输出有所不同。预跑通过后再启动正式运行。
3. 正式保存 100 道题各 3 份原始输出，逐条核对题目、样本序号、种子和原判分，生成 100 条投票结果。已完成记录可在相同配置下继续。投票时保留原始样本，便于独立复算和检查改对、改错案例。
4. 比较表如实记录正确率和成本。持平或下降也可以通过完整性验收。

## 运行

在本目录运行下列命令，需要 Python 3.11 或以上，只使用标准库。运行器复用 `Direct_CoT` 的已验收权重和 Windows Vulkan 后端。

```powershell
python .\run_self_consistency.py pilot
python .\run_self_consistency.py formal
python .\run_self_consistency.py formal --analysis-only
```

正式文件保存到 `results/formal/`。`records.jsonl` 为全部采样，`paired_scores.csv` 为逐题评分，`vote_records.jsonl` 为每题的投票依据。`summary.json` 保存统计结果。
