# 自适应 Solver–Verifier 实验协议与验收

在同一批 100 道 SciBench 上，对照原 CoT、每题复核、按规则触发复核。沿用原 Qwen3-1.7B Q4_K_M 的贪心 CoT 原始回答、题库和判分。复核由同一个模型重新检查推导和最终答案。

## 固定路由与复核

- **触发规则。** 原回答无法解析出最终答案，或最终单位与题目指定单位不同，就触发。若数值与单位均能解析，查找 JSON 前最后一条可识别的、用指定单位写出的数值结论。支持明确等号、约等号、冒号或 `is` / `equals` 后的数值，识别常见科学记数法和 LaTeX 单位写法。该数值与最终 JSON 的差超过两者较大绝对值的 1% 时触发。找不到明确结论时不触发这一条。
- **复核。** 用原题、指定单位及原 CoT 文本提示同一个模型检查公式、条件、算术和单位，输出简短推导和同格式的最终答案。使用相同 llama.cpp b12404、权重、设备、贪心解码和 768 token 上限。复核输出可解析且单位匹配时采用，否则保留原答案。路由、复核提示和采用规则只用题目及模型输出。参考数值只用于评估。
- **共享记录。** 先记录全部 100 道题的复核输出，供“每题复核”使用。自适应组在同一份记录上重放，只采用被触发的复核结果。自适应组的成本按实际触发题的复核调用、token 和耗时相加计算，复核与自适应组使用完全相同的候选修订。
- **统计。** 原 CoT、全量复核、自适应复核均记录 1% 与 5% 数值容差结果、复核比例、改对及改错题数、输入与输出 token 及推理耗时。配对差值按题目家族重采样给出 95% 区间。路由思路来自已观察过的错误，结果作为同一测试集上的探索性对照。

## 验收

1. 离线验证格式与单位触发、科学记数法差异触发、尾数舍入不触发、找不到明确结果的情况，以及无效复核回退。
2. 使用原实验预跑的 4 道题，保存每题的复核记录，逐条核对路由、复核提示、采用决定和判分。至少 3 份复核输出要能解析且单位匹配。预跑的答题正确率不作为通过条件。
3. 正式运行完成后核对 100 份原 CoT、100 份新增复核和 100 条路由记录。用独立脚本复算评分、路由与采纳策略，核查改对、改错及触发率。验收与增益方向无关。

## 运行

在本目录使用 Python 3.11 或以上运行，权重和 llama.cpp 从 `Direct_CoT` 复用。

```powershell
python .\run_solver_verifier.py pilot
python .\run_solver_verifier.py formal
python .\run_solver_verifier.py formal --analysis-only
```

正式输出保存到 `results/formal/`。`config.json` 固定运行记录，`reviews.jsonl` 保存完整复核文本，`routing.jsonl` 保存触发依据，`paired_scores.csv` 和 `summary.json` 保存逐题结果与汇总。
