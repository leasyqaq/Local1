# 程序化答案校验实验协议

本实验重放已保存的 100 份 SciBench 贪心 CoT 输出，用确定性规则修复最终答案中漏写的科学记数法指数。沿用原 Qwen3-1.7B Q4_K_M 实验的题目和判分代码，比较原 CoT、每题模型复核、自适应模型复核和程序校验。见 [原实验](../Direct_CoT/实验结果.md) 与 [模型复核实验](../Adaptive_Solver_Verifier/实验结果.md)。

## 固定规则

同时满足以下条件时，才修改最终答案：

1. 原输出中只有一份可解析的答案 JSON，含 `answer`、`unit` 两项，单位与题目指定单位一致。`answer` 必须是未带指数的 JSON 数值字面量。
2. 在 JSON 之前找到最后一条带指定单位的明确数值结论，沿用自适应路由器的正文结论识别规则。该结论必须显式带非零指数，例如 `4.747 × 10^14 Hz`。
3. 最终答案的数值与正文的尾数精确一致。只把正文已有的指数补回 JSON，保留其余推导和单位。所有其他输出原样通过。

规则只读取模型的原始文本和题目指定单位，参考数值只进入原评分器。记录所有修改，包括原数值、正文结论、指数和修改后答案。按同一题集报告 1% 与 5% 容差准确率、改对、改错及未改变正误的题数。该规则来自已经观察过的正式题错误，这轮重放属于探索性分析。

## 验收

1. 用合成文本检查正负指数、JSON 尾数与正文尾数不符、单位不符、原答案已有指数、格式不合法和正文没有明确科学记数法等情况。
2. 在与正式题集无已标记家族重叠的 4 份已验收 CoT 预跑记录上重放，核对改动格式、原文保留与评分。预跑用于运行检查。
3. 在锁定代码、规则和输入哈希后重放 100 份正式答案。核对无重复、无缺题、每次修改都能追溯到原文，并独立复算修改前后的题目成绩。保留改对和改错，验收不依赖分数提升。

运行需要 Python 3.11+。权重、GPU 和新的模型调用均不参与重放。

```powershell
python .\run_programmatic_verifier.py pilot
python .\run_programmatic_verifier.py formal
python .\verify_results.py formal
```

`results/formal/` 保存 `config.json`、`paired_scores.csv`、`repairs.jsonl` 和 `summary.json`。原 CoT 与模型复核的实验文件各自保留。
